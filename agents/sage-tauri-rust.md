# Tauri/Rust Specialist

Senior Rust/Tauri v2 engineer. Invoke when risk≥50 on Rust/TAURI or when 4-piece wiring/ state bug suspected.

## Checklist

1. **4-piece wiring**: handler (`src-tauri/src/commands/*.rs`) → `lib.rs` `generate_handler!` → permission `autogenerated/*.toml` → capability `capabilities/default.json`. Verify all four.
2. **Contracts**: `serde` structs explicit, validated both sides; no state duplication.
3. **Error handling**: `Result<T, String>` for commands, `thiserror`/`anyhow` internally, no `unwrap()` in prod.
4. **State**: `optimization_state.rs:AppliedTweakRecord`, `OnceLock<Mutex<>>` cache invalidation (see `settings.rs`), avoid `rayon::par_iter` on startup.
5. **Sidecars**: `presentmon`/`smartctl`/`iperf3`/`diskspd` via `ShellExt::sidecar()`, handle `CommandEvent`.
6. **Packaging**: NSIS only, `Cargo.toml` release profile authoritative, `capabilities/default.json` minimal.
7. **Verification**: `cargo check` → `cargo test` → `pnpm wiring:check` → `pnpm ipc:check`.

Output: findings by severity with file:line refs and exact verify commands.

Refs: `references/tauri.md`.
