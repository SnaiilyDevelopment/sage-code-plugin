# Tauri v2 + Rust — SageTweaks

## Stack

- Tauri 2.9, Rust 1.85, React 19, Vite 6, Zustand + TanStack Query.
- `src-tauri/tauri.conf.json`: `productName SageTweaks`, `identifier com.sagetweaks.desktop`, `targets ["nsis"]`, `installMode perMachine`, `requireAdministrator` via `capabilities/default.json` permissions.
- External binaries: `presentmon`, `smartctl`, `iperf3`, `diskspd` in `src-tauri/binaries/*-x86_64-pc-windows-msvc.exe`.

## 4-Piece Wiring (must stay in sync)

1. **Handler**: `src-tauri/src/commands/*.rs` — `#[tauri::command]` fn
2. **Registration**: `src-tauri/src/lib.rs` (or `main.rs`) `.invoke_handler(tauri::generate_handler![...])`
3. **Permission**: `src-tauri/permissions/autogenerated/*.toml` — `allow-<command>` entry; generated via `pnpm build` / Tauri CLI
4. **Capability**: `src-tauri/capabilities/default.json` — exposes permission to `main` window

Break any piece → IPC silently fails. Verify with `pnpm wiring:check` and `pnpm ipc:check`.

## IPC Contracts

- Keep contracts explicit: `serde` structs in `src/types/` + `src-tauri/src/*.rs`, validated on both sides.
- Never duplicate state between Rust and frontend — single source of truth.
- Error handling: return `Result<T, String>` from commands; frontend shows via `sonner` toast.

## State & Sidecars

- `optimization_state.rs:AppliedTweakRecord` — persists applied tweaks.
- Sidecars (`presentmon` etc.) via `tauri_plugin_shell::ShellExt::sidecar()` — handle `CommandEvent` streams, avoid blocking main thread.
- Avoid `rayon::par_iter` on startup hot path (causes contention); prefer lazy loading (`lazy()` for `LicenseEntryScreen`, `OnboardingWizard`).

## Checks

- `cargo check` / `cargo test` in `src-tauri/`
- `pnpm wiring:check` / `pnpm ipc:check` / `pnpm security:policy`
- `tauri.conf` `capabilities: ["default"]` only — single capability set.

## Packaging

- NSIS only — `bundle.windows.wix` block dead, `icons/icon.icns` removed.
- `src-tauri/.cargo/config.toml` no longer overrides `[profile.release]` — `Cargo.toml` is authoritative (lto, codegen-units, panic=abort).
