### Architecture

### Conventions
- `CLAUDE.md` = why, `AGENTS.md` = what, `.claude/rules/*.md` = how. One fact lives in one place.
- Load order: `AGENTS.md` → `.wolf/anatomy.md` → `cerebrum.md` → `memory.md` → `docs/agent-context.md`.

### Build / Test Commands
- `pnpm dev` / `pnpm build` / `pnpm type-check` / `pnpm lint` / `pnpm test`

- `pnpm wiring:check` / `pnpm ipc:check` / `pnpm security:policy`
- `pnpm tauri:build` (slow, only on release)

### Windows Knowledge
- `HKCU` safe, `HKLM` elevated. `HKLM\SYSTEM\CurrentControlSet\Services` — boot-critical.
- Win10 vs 11: DWM/scheduler/power differences — see `references/windows.md`.

### Known Problems
- `src-tauri/.cargo/config.toml` previously overrode release profile — now fixed, Cargo.toml authoritative.
- `bundle.windows.wix` dead block — NSIS only.
- `rayon::par_iter` on startup causes contention.

### Known Solutions
- Snapshot → modify → re-read → verify for every tweak.
- Lazy-load `LicenseEntryScreen` / `OnboardingWizard`.
- `settings.rs` `OnceLock<Mutex<Option<...>>>` mtime-keyed cache.

### Performance Baselines
- Record per-hardware: OS build, driver, power plan. Use `scripts/verification/benchmark.py`.

### Release Process
- Version in `package.json` + `tauri.conf.json` must stay in sync. `createUpdaterArtifacts: true`, endpoints: `sagetweaks.com/api`, `downloads.sagetweaks.com`.
