# Security

- Treat privilege escalation and system modification as high risk (risk≥50). Require review for elevation paths.
- Never expose secrets or tokens — `license.dat`, `hwid.dat`, `audit_signing.key`, `supabase service_role`, `stripe_secret` never in diff/log/telemetry.
- Validate untrusted input before shell/process/file use (CWE-78/20). Sanitize IPC args, file paths, registry values.
- Review destructive operations and `allow-*` permission sprawl (`pnpm security:policy`).
- Keep least privilege: single `capabilities/default.json` set, minimal `autogenerated/*.toml` allows.
- Check input validation, file access boundaries, and CSP (`tauri.conf.json` `csp`).
