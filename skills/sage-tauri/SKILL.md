# Sage Tauri + Rust

Canonical Tauri/Rust expertise (alias: `tauri-rust`).

## Tauri v2 Contracts

- **4-piece wiring**: handler (`src-tauri/src/commands/*.rs` `#[tauri::command]`) → `lib.rs` `generate_handler!` → permission `autogenerated/*.toml` → capability `capabilities/default.json`. Break any → silent IPC failure.
- **Verification**: `cargo check` → `cargo test` → `pnpm wiring:check` → `pnpm ipc:check` → `pnpm security:policy`.
- Keep IPC contracts explicit (`serde` structs, `src/types/`), validated both sides. No state duplication between Rust and frontend.

## Rust

- Idiomatic error handling (`Result<T, String>` for commands, `thiserror`/`anyhow` internally), avoid `unwrap()` in production paths.
- Avoid `rayon::par_iter` on startup hot path; lazy-load `LicenseEntryScreen`/`OnboardingWizard`.
- `optimization_state.rs:AppliedTweakRecord` is source of truth for applied tweaks.

## Sidecars & Packaging

- Sidecars (`presentmon`, `smartctl`, `iperf3`, `diskspd`) via `ShellExt::sidecar()`, handle `CommandEvent` streams.
- NSIS only — `wix` block dead. `Cargo.toml` `[profile.release]` authoritative.
